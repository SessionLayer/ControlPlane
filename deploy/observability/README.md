# Control Plane observability assets

Prometheus alert rules (`prometheus-slo-rules.yaml`) and a Grafana dashboard
(`grafana-slo-dashboard.json`) for the Control Plane's SLOs and CA-signer
availability. See `docs/operations/monitoring.md` in the
[Documentation](https://github.com/SessionLayer/Documentation) repo for the
SLOs, the panels, and how these rules fit the platform's RED/saturation
signals.
